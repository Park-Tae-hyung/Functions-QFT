## 13차 업데이트 (✍️ 개념마다 노트 · 문제마다 풀이 노트와 그래프 도구 · 🖥️ 학생 풀이 화면 · 🙈 이름 가리기)

- **「📝 개념 노트」 탭을 없애고, 노트를 개념 학습 안으로 옮겼어요.** 개념마다 ① 개념 이해(영상·교과서 펼치기) 바로 다음에 「📝 내 노트」 카드가 있어요.
  - 🔑 단서 · ✍️ 필기 · 📌 요약의 **코넬 노트**와 **그래프·식·그림 노트**(손글씨)가 개념별로 따로 저장돼요.
  - 그래프를 다루는 개념(그래프 · 점근선 · 평행이동 · 대칭 등)에는 **📈 그래프 그리기 도구**도 함께 있어요.
- **문제마다 풀이 노트** : 「📘 개념 학습」의 예제·확인 문제와 「✏️ 실력 다지기」 문제 중 풀이가 필요한 문제(답을 직접 쓰는 문제, 풀이가 긴 문제) 아래에 「✍️ 풀이 노트 — 그래프 · 식 · 그림」(눌러서 펼치기)이 있어요. 그래프를 그려 푸는 문제에는 「📈 그래프 그리기 도구」도 있어요.
- **📈 그래프 그리기 도구 (지오지브라처럼)** : `y =` 칸에 식을 넣으면 바로 그래프가 그려져요.
  - 식은 5개까지, 색으로 구분돼요. 예) `1/(x-1)+3` · `√(2x-4)+1` · `x^2-2x` · `|x|`
  - 세로선 `x=1`, 점 `(2,1)`도 그릴 수 있고, 점근선 근처는 끊어서 그려요.
  - 끌어서 움직이고 ＋ － ⌂ 로 확대·축소해요. 마우스를 올리면 그 x에서의 y 값이 보여요.
  - 식이 틀리면 「괄호 ) 가 빠졌어요」처럼 알려 줘요. 계산기는 직접 만든 것이라 인터넷 없이도 작동해요.
- **자동 저장** : 노트·손글씨·그래프·고른 답이 쓰는 즉시 저장돼요(서버 표 `qf_work`). 손글씨는 그림 파일이 아니라 선의 좌표로 저장해서 가볍고, 선생님 화면에서도 또렷하게 다시 그려져요. 인터넷이 끊기면 그 기기에 임시 보관했다가 다시 연결되면 올라가요. 예전 개념 노트 탭에 써 둔 노트는 첫 개념의 노트 카드에서 「📦 예전 노트 보기」로 볼 수 있어요.
- **🖥️ 학생 풀이 화면 (선생님 탭 › 🖥️ 학생 풀이 화면)**
  - 개념이나 문제를 고르면, 선택한 반 학생 전체의 기록이 카드로 한 화면에 보여요(고른 답과 정답 여부, 몇 번째 시도, 코넬 노트, 손글씨 풀이, 그래프와 식).
  - **학생 카드를 누르면 그 학생의 화면 전체**(모든 개념 노트, 문제 풀이, 손글씨, 그래프)가 열리고, 「← 이전 학생 / 다음 학생 →」으로 넘겨 볼 수 있어요.
  - 「15초마다 자동 새로고침」을 켜 두면 수업 중 학생들이 쓰는 대로 화면이 바뀌어요.
- **🙈 학번·이름 가리기** : 선생님으로 입장하면 「🗳️ 질문 광장」의 질문마다 쓴 학생이 보이고, 「🙈 학번·이름 가리기」 단추로 숨길 수 있어요(학생 풀이 화면에도 같은 단추가 있어요). TV에 띄울 때 쓰세요. 이 설정은 그 컴퓨터에 기억돼요.
- 세특 초안 : 개념별 코넬 노트와 손글씨·그래프 풀이 기록도 근거로 써요(「식과 그래프를 직접 그려 가며 풀이 과정을 시각적으로 정리함」 등).

## 11차 업데이트 (📖 살아 움직이는 교과서 — 펼치면 입체로 일어서는 개념 영상 + 목소리 설명)

참고 영상(3D 팝업 물리 교과서)과 newtons-lab 사이트(책상 위 교과서 → 쪽마다 팝업 모형 + 음성 + 자막 + 쪽 넘기기)의 방식을 분석해, 6개 차시 **26개 개념 모두**에 적용했습니다.

- **개념마다 3가지를 새로 만들었습니다** (모두 Higgsfield)
  1. **입체 팝업 교과서 그림** 26장 (GPT Image 2.6) : 왼쪽 쪽에는 교과서 제목과 핵심 문장, 오른쪽 쪽에는 그 개념의 그림이 흰 종이 모형으로 일어선 모습. 교과서(비상 김원경) 101~126쪽의 개념 탐구·예제를 그대로 썼습니다. 예) 101쪽 토종견 → 원서식지 대응, 107쪽 \(f(x)=x-2,\ g(x)=3x+1\), 109쪽 임진왜란 3대 대첩, 117쪽 연비 \(y=\frac{400}{30-x}\), 120쪽 예제 \(y=\frac{2}{x+1}-2\), 122쪽 지진 해일 \(v=\sqrt{9.8x}\), 126쪽 예제 \(y=\sqrt{2x-4}+1\).
  2. **그림이 책 밖으로 솟아오르는 영상** 26개 (Kling 3.0, 5초) : 같은 그림을 평면 잉크 그림으로 인쇄한 쪽(시작 화면)에서 입체 모형(끝 화면)으로 일어서는 장면.
  3. **입체 모형이 계속 움직이는 모션 그래픽** 26개 (Kling 3.0, 5초) : 구슬이 대응 화살표·곡선을 따라가고, 점근선으로 다가가고, 파도가 치는 등 개념에 맞는 움직임. **「📘 개념 학습」의 개념 카드 맨 위 모션 그래픽이 모두 이 영상으로 바뀌었습니다.**
- **목소리 설명 26개** (Higgsfield · Qwen TTS, 선생님이 고르신 「Julian」 목소리) : 밝고 다정한 젊은 남자 목소리로 교과서 쪽수 → 정의 → 예 → 기억할 점 순서로 20~40초 설명합니다. AI 음성이며 실제 아이돌이나 특정 인물의 목소리를 흉내 낸 것이 아닙니다.
- **사용법** : 개념 카드의 모션 그래픽 아래 **「📖 교과서 펼치기」** 단추 → ① 교과서 그림 → ② 그림이 책 밖으로 → ③ 살아 움직이는 개념 순서로 영상이 이어지고, 목소리에 맞춰 자막(수식 포함)이 넘어갑니다. ⏸ 잠깐 멈춤 · ↻ 처음부터 · ← 이전 개념 / 다음 개념 → · 🔊 소리 끄기 · 번호 단추로 개념 이동 · 키보드(←, →, 스페이스, Esc).
  - 자막은 음성의 쉬는 곳을 분석해 둔 시각에 맞춰 넘어갑니다. 음성을 못 불러오면 자막만 시간에 맞춰 넘어가고, 브라우저가 소리 자동 재생을 막으면 큰 ▶ 단추가 뜹니다.
- **검증** : 26장의 그림을 한 장씩 눈으로 확인했습니다(식·그래프의 모양·점근선·정의역·한글 표기). 틀린 그림은 다시 만들었습니다. 다만 AI 영상이라 움직이는 동안 작은 글씨가 잠깐 흐려질 수 있고, 폴리그래프 게임판의 작은 그래프 카드는 분위기를 보여 주는 그림입니다. 정확한 정의와 식은 영상 아래 개념 카드와 교과서가 기준입니다(영상 창에도 이 안내가 적혀 있습니다).
- 영상·음성은 선생님 Higgsfield 계정 저장 공간(CDN)에서 불러옵니다. Higgsfield에서 해당 생성물을 지우면 보이지 않습니다. 대본은 `gen/narr.py`, 생성물 목록은 `site/pop.js`에 있습니다.

## 10차 업데이트 (🎞️ 모션 그래픽이 실제로 움직이도록 수정 · 생동감 있는 디자인)

- **원인** : 선생님 컴퓨터는 윈도우 「설정 › 접근성 › 시각 효과 › 애니메이션 효과」가 꺼져 있어서, 브라우저가 「동작 줄이기(prefers-reduced-motion)」를 켠 상태였습니다. 예전 코드는 이 신호를 보면 모션 그래픽 재생과 화면 움직임을 모두 멈췄습니다. 학교 PC도 이 설정이 꺼져 있는 경우가 많습니다. (영상 파일과 CDN은 정상 : 선생님 브라우저에서 1280×720 영상이 바로 재생되는 것을 확인)

- **🧠 질문 코치 (API 키 · 외부 AI 없음)** : Gemini 연결을 없애고, 사이트 안의 「질문 코치 엔진」이 학생 기기에서 바로 분석합니다. 설정할 것이 없고 학생 글이 외부 AI 회사로 나가지 않습니다.
  - 🧠 질문 평가받기 : 좋은 질문 5기준 10점 + 한 칸 올리기 실마리. 진술문은 「질문으로 바꾸기」, 수업과 관계없는 글은 질문 초점으로 안내, 「라면」만 붙은 가짜 If 질문은 바꿀 조건을 쓰게 함
  - 🚀 창의적으로 키우기 : 조건 바꾸기 · 반대로 뒤집기 · 일반화 · 생활과 연결 · 극단으로 보내기 중 3개의 질문 씨앗 (누를 때마다 다른 조합)
  - 🧭 나만의 질문 찾기 : 막연한 느낌을 되묻기 3개와 질문 시작 문장으로
  - 📒 노트·질문지 점검 : 빠진 핵심 개념, 정의·예시·주의 구성, 요약, 질문지 수준, 차시별 오개념 사전(예: f⁻¹=1/f, 합성함수 교환법칙 성립, 치역=공역)
  - 차시마다 「바꿔 볼 조건」, 「생활 장면」, 「오개념」을 따로 넣어 실마리가 그 차시 내용에 맞게 나옵니다. 규칙으로 분석하는 도구라 점수는 참고용입니다.
- **🗑 질문 삭제 (선생님 탭)** : 「💬 질문 전체」에서 질문마다 🗑 삭제, 답글마다 ✕, 체크 후 「선택한 질문 삭제」로 여러 개 한 번에. 삭제하면 그 질문의 답글·공감도 함께 지워지고 되돌릴 수 없습니다(잠시 감추려면 「숨기기」).
- **입장 창 자동완성 막기** : 브라우저에 저장된 이메일(아이디)이 이름 칸에 저절로 들어가던 문제를 고쳤습니다. 입장 칸은 브라우저 자동완성을 받지 않고, 이메일이 들어가 있으면 지우며, 이메일로는 입장할 수 없게 했습니다. 선생님 암호 칸도 저장된 비밀번호가 자동으로 들어가지 않게 했습니다.
- 선생님 탭 「🧠 질문 코치 기록」 : 학생별 코치 사용 횟수, 질문 평가 점수(평균·최고), 기록 CSV
- 서버 : RPC `qf_ai_save`(코치 기록, 학생당 1시간 200회), `qf_teacher_delete`(여러 개 삭제), `qf_teacher_act`에 `delete` 추가. 이전에 만든 서버 함수 `qf-ai`(Gemini용)는 더 이상 쓰지 않습니다.

## 3차 업데이트 (성우 낭독 · 영상 정리 · 탭 이동)

- **🎧 성우가 읽어주기** : 「책 속 질문·토론」 탭의 글 9편마다 버튼이 있습니다. 누르면 글의 내용과 분위기에 맞는 한국어 AI 성우가 읽어 줍니다. 재생·일시정지, 진행 막대(눌러서 원하는 곳으로 이동), 느리게·보통·빠르게를 쓸 수 있고, 읽는 동안 그 글 상자가 빛납니다. 다른 탭으로 가면 자동으로 멈춥니다.

| 글 | 목소리 | 분위기 |
|---|---|---|
| f1 오일러 | 차분한 노학자 | 서재에서 생각을 정리하듯 또박또박 |
| f1 디리클레 | 엄밀한 수학자 | 정의를 선언하듯 단호하게 |
| f2 앨리스 | 밝은 동화 이야기꾼 | 놀라는 앨리스, 느긋한 애벌레를 연기 |
| f3 카이사르 · 아우구스투스 | 묵직한 로마 역사가 | 비밀을 털어놓듯 낮고 은밀하게 |
| r1 아리스토텔레스(제논) | 깊은 목소리의 철학자 | 수수께끼를 내듯 천천히 |
| r2 · r3 갈릴레이 | 열정적인 과학자 (두 차시 같은 목소리) | 발견을 발표하듯 / 진자처럼 리듬감 있게 |
| r3 히파소스 전설 | 신비로운 이야기꾼 | 오래된 전설처럼 나지막하고 서늘하게 |

  - Higgsfield의 Qwen TTS(한국어)로 만든 **AI 음성**이며, 화면에 「실제 성우·저자의 목소리가 아니에요」라고 표시했습니다.
  - 음성 파일도 그림처럼 선생님 Higgsfield 저장 공간에서 불러오므로 인터넷이 연결되어 있어야 합니다.
- **유튜브 영상 정리** : 학원·인터넷 강의 강사의 개념·문제 풀이 강의 영상 29개를 모두 뺐습니다. 방송(YTN 사이언스, 차이나는 클라스 등), 수학사 이야기, 과학 실험 영상만 남겼습니다 (f1 1개, f2 0개, f3 3개, r1 4개, r2 2개, r3 4개). 합성함수(f2)는 남길 영상이 없어 「인터넷 도구」로 대신하도록 안내 문구를 넣었습니다.
- **탭 이동 고침** : 컴퓨터·태블릿 화면(가로 600px 이상)에서는 10개 탭이 두 줄로 모두 보입니다. 휴대폰처럼 좁은 화면에서는 양옆 ‹ › 화살표 버튼, 마우스로 끌기, 마우스 휠로 넘길 수 있고, 누른 탭은 자동으로 가운데로 옵니다. 선생님 화면의 표처럼 옆으로 긴 영역도 마우스로 끌어서 넘길 수 있습니다.

## 학생 사용법

1. 학번과 이름으로 입장합니다. 한 번 입장하면 같은 브라우저에서 6개 차시 모두 이어서 씁니다.
2. 질문을 쓰면 **What / How·Why / If** 수준과 **닫힌·열린 질문**이 자동으로 표시됩니다. 학생이 직접 바꿀 수도 있습니다.
3. 친구들에게는 이름이 보이지 않습니다. 선생님 화면에서는 학번이 보이며, 자유 질문방 글은 기본이 「익명」입니다. 「작성자 보기」를 켤 때만 학번이 보입니다.

## 선생님 사용법

- 처음 암호는 **question2026** 입니다. 「선생님」 탭 → 「암호 바꾸기」에서 꼭 바꿔 주세요. 6개 차시가 같은 암호를 씁니다.
- 학생 질문에 **답변**을 달면 학생 화면에 「🧑‍🏫 선생님」으로 표시됩니다. 질문이 그냥 사라지지 않도록 회수해 주는 기능입니다.
- **📌 채택**한 질문은 학생 화면에 표시되어 다음 활동의 탐구 질문이 됩니다.
- 워드클라우드의 단어를 누르면 그 화면에서 숨길 수 있습니다.
