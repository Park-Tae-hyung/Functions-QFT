## 2차 업데이트 (교과서 디자인 · 입체감 · 이미지 · 예제)

- **교과서 예제 5개 추가** (풀이 포함) : 합성함수 예제 1(107쪽), 역함수 예제 1(111쪽), 유리함수 예제 1·2(120~121쪽), 무리함수 예제 1(126쪽). 3-1의 01 소단원과 3-2 교과서에는 이 밖의 「예제」가 없습니다.
- **교과서 느낌 디자인** : 남색 단원 경로 띠, 노란 고리의 소단원 번호, 녹색 머리띠 제목, 「예제」 보라 배지, 모눈 종이 배경
- **입체감** : Higgsfield(GPT Image 2.6)로 만든 3D 장면. 마우스를 움직이면 그림이 기울어지고, 카드와 버튼도 입체로 보입니다.
- **이미지 41장** : 홈 3장, 차시별 3D 대표 장면 6장, 개념 사진 6장, 실생활 실사 사진 18장, 책 그림 8장. 모두 AI로 생성했고 화면에 「AI 생성 이미지」라고 표시했습니다.
- **책 그림** : 저작권이 끝난 원전의 실제 표지 사진은 이 작업 환경에서 내려받을 수 없어서, 글의 분위기를 살린 상상 그림을 AI로 만들었습니다. 학생들이 오해하지 않도록 「실제 책 표지 아님」이라고 적어 두었습니다.
- **글씨 · 수식 크게** : 본문은 약 10%, 수식은 약 15~30% 키웠습니다.
- 이미지는 선생님 Higgsfield 계정의 저장 공간(CDN)에서 불러옵니다. Higgsfield에서 해당 생성물을 지우면 그림이 보이지 않게 됩니다. 그래도 수업 기능은 그대로 작동합니다.

## 5차 업데이트 (API 키 없는 질문 코치 · 질문 삭제)

- **🧠 질문 코치 (API 키 · 외부 AI 없음)** : Gemini 연결을 없애고, 사이트 안의 「질문 코치 엔진」이 학생 기기에서 바로 분석합니다. 설정할 것이 없고 학생 글이 외부 AI 회사로 나가지 않습니다.
  - 🧠 질문 평가받기 : 좋은 질문 5기준 10점 + 한 칸 올리기 실마리. 진술문은 「질문으로 바꾸기」, 수업과 관계없는 글은 질문 초점으로 안내, 「라면」만 붙은 가짜 If 질문은 바꿀 조건을 쓰게 함
  - 🚀 창의적으로 키우기 : 조건 바꾸기 · 반대로 뒤집기 · 일반화 · 생활과 연결 · 극단으로 보내기 중 3개의 질문 씨앗 (누를 때마다 다른 조합)
  - 🧭 나만의 질문 찾기 : 막연한 느낌을 되묻기 3개와 질문 시작 문장으로
  - 📒 노트·질문지 점검 : 빠진 핵심 개념, 정의·예시·주의 구성, 요약, 질문지 수준, 차시별 오개념 사전(예: f⁻¹=1/f, 합성함수 교환법칙 성립, 치역=공역)
  - 차시마다 「바꿔 볼 조건」, 「생활 장면」, 「오개념」을 따로 넣어 실마리가 그 차시 내용에 맞게 나옵니다. 규칙으로 분석하는 도구라 점수는 참고용입니다.
- **🗑 질문 삭제 (선생님 탭)** : 「💬 질문 전체」에서 질문마다 🗑 삭제, 답글마다 ✕, 체크 후 「선택한 질문 삭제」로 여러 개 한 번에. 삭제하면 그 질문의 답글·공감도 함께 지워지고 되돌릴 수 없습니다(잠시 감추려면 「숨기기」).
- 선생님 탭 「🧠 질문 코치 기록」 : 학생별 코치 사용 횟수, 질문 평가 점수(평균·최고), 기록 CSV
- 서버 : RPC `qf_ai_save`(코치 기록, 학생당 1시간 200회), `qf_teacher_delete`(여러 개 삭제), `qf_teacher_act`에 `delete` 추가. 이전에 만든 서버 함수 `qf-ai`(Gemini용)는 더 이상 쓰지 않습니다.

## 3차 업데이트 (성우 낭독 · 영상 정리 · 탭 이동)

- **🎧 성우가 읽어주기** : 「책 속 질문·토론」 탭의 글 9편마다 버튼이 있습니다. 누르면 글의 내용과 분위기에 맞는 한국어 AI 성우가 읽어 줍니다. 재생·일시정지, 진행 막대(눌러서 원하는 곳으로 이동), 느리게·보통·빠르게를 쓸 수 있고, 읽는 동안 그 글 상자가 빛납니다. 다른 탭으로 가면 자동으로 멈춥니다.

| 글 | 목소리 | 분위기 |
|---|---|---|
| f1 오일러 | 차분한 노학자 | 서재에서 생각을 정리하듯 또박또박 |
| f1 디리클레 | 엄밀한 수학자 | 정의를 선언하듯 단호하게 |
| f2 앨리스 | 밝은 동화 이야기꾼 | 놀라는 앨리스, 느긋한 애벌레를 연기 |
| f3 카이사르 · 아우구스투스 | 묵직한 로마 역사가 | 비밀을 털어놓듯 낮고 은밀하게 |
| r1 아리스토텔레스(제논) | 깊은 목소리의 철학자 | 수수께끼를 내듯 천천히 |
| r2 · r3 갈릴레이 | 열정적인 과학자 (두 차시 같은 목소리) | 발견을 발표하듯 / 진자처럼 리듬감 있게 |
| r3 히파소스 전설 | 신비로운 이야기꾼 | 오래된 전설처럼 나지막하고 서늘하게 |

  - Higgsfield의 Qwen TTS(한국어)로 만든 **AI 음성**이며, 화면에 「실제 성우·저자의 목소리가 아니에요」라고 표시했습니다.
  - 음성 파일도 그림처럼 선생님 Higgsfield 저장 공간에서 불러오므로 인터넷이 연결되어 있어야 합니다.
- **유튜브 영상 정리** : 학원·인터넷 강의 강사의 개념·문제 풀이 강의 영상 29개를 모두 뺐습니다. 방송(YTN 사이언스, 차이나는 클라스 등), 수학사 이야기, 과학 실험 영상만 남겼습니다 (f1 1개, f2 0개, f3 3개, r1 4개, r2 2개, r3 4개). 합성함수(f2)는 남길 영상이 없어 「인터넷 도구」로 대신하도록 안내 문구를 넣었습니다.
- **탭 이동 고침** : 컴퓨터·태블릿 화면(가로 600px 이상)에서는 10개 탭이 두 줄로 모두 보입니다. 휴대폰처럼 좁은 화면에서는 양옆 ‹ › 화살표 버튼, 마우스로 끌기, 마우스 휠로 넘길 수 있고, 누른 탭은 자동으로 가운데로 옵니다. 선생님 화면의 표처럼 옆으로 긴 영역도 마우스로 끌어서 넘길 수 있습니다.

## 학생 사용법

1. 학번과 이름으로 입장합니다. 한 번 입장하면 같은 브라우저에서 6개 차시 모두 이어서 씁니다.
2. 질문을 쓰면 **What / How·Why / If** 수준과 **닫힌·열린 질문**이 자동으로 표시됩니다. 학생이 직접 바꿀 수도 있습니다.
3. 친구들에게는 이름이 보이지 않습니다. 선생님 화면에서는 학번이 보이며, 자유 질문방 글은 기본이 「익명」입니다. 「작성자 보기」를 켤 때만 학번이 보입니다.

## 선생님 사용법

- 처음 암호는 **question2026** 입니다. 「선생님」 탭 → 「암호 바꾸기」에서 꼭 바꿔 주세요. 6개 차시가 같은 암호를 씁니다.
- 학생 질문에 **답변**을 달면 학생 화면에 「🧑‍🏫 선생님」으로 표시됩니다. 질문이 그냥 사라지지 않도록 회수해 주는 기능입니다.
- **📌 채택**한 질문은 학생 화면에 표시되어 다음 활동의 탐구 질문이 됩니다.
- 워드클라우드의 단어를 누르면 그 화면에서 숨길 수 있습니다.

## 데이터 저장 (Supabase)

- 저장되는 표: `qf_students`, `qf_posts`(질문·답글), `qf_votes`, `qf_responses`(토의·토론·성찰·폴리그래프), `qf_attempts`(풀이 기록), `qf_config`(암호)
- 표에 직접 접근하는 것은 모두 막혀 있습니다. `qf_` 로 시작하는 RPC 함수로만 오갑니다.
- 친구들이 보는 질문 목록에는 학번과 이름이 아예 전달되지 않습니다.

## 깃허브 올리기

`index.html`, `f1.html` ~ `r3.html` 7개 파일을 저장소 맨 위에 그대로 올리면 됩니다. 「명제 탐험대」와 같은 방법입니다.

## 책 원문 안내

- 책 탭에 실은 글은 모두 저작권이 끝난 원전(1638~1865년, 고대 문헌)을 수업용으로 우리말로 옮기거나 줄인 것입니다.
- 저작권이 있는 현대 도서(『코드북』, 『X의 즐거움』 등)는 원문을 싣지 않고 「함께 읽을 책」으로 소개만 했습니다.
